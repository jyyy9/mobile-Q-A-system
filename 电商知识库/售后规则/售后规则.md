# 智汇电商 - 售后规则

## 一、保修政策

### 1.1 保修期限

| 商品类别 | 整机保修 | 配件保修 | 屏幕保修 | 电池保修 |
|---------|---------|---------|---------|---------|
| 旗舰手机(4000元以上) | 1年 | 6个月 | 1年 | 1年（容量低于80%免费换） |
| 中端手机(2000-3999元) | 1年 | 6个月 | 1年 | 1年 |
| 入门手机(2000元以下) | 1年 | 3个月 | 1年 | 1年 |
| 平板电脑 | 1年 | 6个月 | 1年 | 1年 |
| 配件(充电器/耳机等) | 6个月 | - | - | - |

### 1.2 保修范围（免费）

- 非人为损坏的主板故障
- 非人为损坏的屏幕显示异常（亮点/坏点/漏光）
- 非人为损坏的摄像头故障（对焦/成像异常）
- 非人为损坏的按键/接口失灵
- 非人为损坏的电池严重鼓包或续航严重下降
- 扬声器/听筒/麦克风无声或异常
- Wi-Fi/蓝牙/指纹/面容识别模块故障

### 1.3 不在保修范围

- 因摔落、碰撞、挤压等人为因素造成的屏幕碎裂/外壳变形
- 进液、受潮、腐蚀导致的故障（通过内部试纸检测）
- 未经授权的维修、改装、刷机、Root/越狱
- 正常使用中的外观磨损、划痕、氧化
- 因不可抗力（火灾、水灾、地震、雷击等）造成的损坏
- 已过保修期的设备
- 第三方配件导致的设备故障
- 序列号被涂改或无法辨认的设备

### 1.4 保修流程

1. 联系客服说明故障现象
2. 客服初步判断后给出处理方案（寄修/到店维修）
3. 寄修：将设备寄回指定维修中心（运费由商家承担）
4. 维修中心检测：1-3个工作日出具检测报告
5. 确认属于保修范围：免费维修，5-7个工作日内完成
6. 确认不属于保修范围：联系用户确认是否付费维修
7. 维修完成后寄回（运费由商家承担）

### 1.5 备用机服务
- 保修期内，维修超过3个工作日的，可申请提供备用机
- 备用机为同档次机型，用完需归还
- 备用机由顺丰到付寄送

## 二、退换货规则

### 2.1 七天无理由退货

**适用条件：**
- 签收后7天内
- 商品保持完好（包括包装、配件、赠品）
- 手机类必须未激活（未连接WiFi、未插SIM卡、未登录账号）
- 不影响二次销售

**不适用七天无理由的情况：**
- 已激活的手机
- 拆封后无法恢复原包装的贴身配件（如耳机、腕带等）
- 定制商品（刻字、定制颜色等）
- 已使用且有明显使用痕迹的
- 过了退货时效的

### 2.2 质量问题退货/换货

- 签收后15天内出现非人为质量问题：支持换货
- 签收后15天内出现严重质量问题（如无法开机/屏幕不亮）：支持退货
- 同一质量问题维修两次仍未解决：支持退货
- 保修期内维修累计超过30天：支持退货

### 2.3 退款标准

| 情况 | 退款金额 |
|------|---------|
| 符合七天无理由，商品完好 | 全额退款（含原运费） |
| 符合七天无理由，包装丢失 | 扣除包装费50元 |
| 符合七天无理由，配件缺失 | 按配件售价扣除 |
| 质量问题退货 | 全额退款（含来回运费） |
| 使用后七天无理由 | 扣除10%-30%折旧费 |
| 超过退货时效 | 不支持退款 |
| 赠品未退回 | 按赠品价格扣除 |

### 2.4 退款到账时间

| 支付方式 | 退款到账时间 |
|---------|------------|
| 支付宝 | 1-3个工作日原路返回 |
| 微信支付 | 1-3个工作日原路返回 |
| 银行卡 | 3-7个工作日 |
| 购物金 | 即时退回账户 |
| 积分 | 即时退回账户 |
| 组合支付 | 按比例分别退回各渠道 |

## 三、以旧换新

### 3.1 回收估价
- 在线估价：填写手机型号、容量、外观成色、功能状况
- 系统自动出估价，承诺保价48小时
- 实际回收价以质检后为准（会有±10%浮动）

### 3.2 回收流程
1. 下单选择以旧换新
2. 顺丰上门取旧机（免运费）
3. 专业质检（1-2个工作日）
4. 价格确认后抵扣新机款
5. 如价格与估价不符，可取消回收退回旧机（免运费）

### 3.3 回收注意事项
- 旧机需关闭查找我的iPhone/华为帐号等防盗功能
- 建议恢复出厂设置清除个人数据
- 旧机配件需齐全（充电器、数据线等）
- 屏幕碎裂/功能故障的旧机仍可回收，但价格会大幅降低
- 有锁/黑解/妖机/山寨机不予回收

## 五、发票服务

### 5.1 发票类型
- 普通电子发票（默认）：下单后发货时自动开具
- 增值税专用发票：需要提供公司名称、税号、地址、电话、开户行及账号
- 纸质发票：需联系客服单独申请，运费到付

### 5.2 发票抬头
- 个人发票：默认使用收货人姓名
- 企业发票：可在订单备注填写公司名称和税号
- 发票抬头确认后不可修改，请仔细核对

### 5.3 补开/重开发票
- 缺开发票：联系客服，3-5个工作日补开
- 发票信息错误：联系客服作废重开
- 纸质发票丢失：不可补开，可提供发票复印件或盖章证明

1. 所有本店售出的手机均享受一年官方保修服务，自签收之日起计算。
