# 智汇电商 - 退换货政策

## 一、退换货时效

| 商品类别 | 退货时效 | 换货时效 |
|----------|----------|----------|
| 电子产品 | 签收后7天内 | 签收后15天内 |
| 服装鞋帽 | 签收后15天内 | 签收后30天内 |
| 家居用品 | 签收后7天内 | 签收后15天内 |
| 图书音像 | 签收后7天内 | 不支持换货 |
| 食品生鲜 | 不支持退货 | 签收后24小时内 |

## 二、退货条件

1. 商品需保持原包装完整，配件齐全
2. 电子产品需未激活（手机、平板、笔记本等）
3. 贴身衣物、食品、定制商品不支持七天无理由退货
4. 退货商品需附带原始发票或购买凭证

## 三、手机类商品特殊规定

- 手机产品支持签收后 **7天内** 退货，**15天内** 换货
- 退货手机必须**未激活**（未连接WiFi、未登录账号、未插入SIM卡）
- 外观需完好，无划痕、无磕碰
- 需保留原装充电器、数据线、卡针等全部配件
- 已激活的手机不支持七天无理由退货，如有质量问题可申请换货

## 四、退货流程

1. 登录账号 → 我的订单 → 申请退货
2. 填写退货原因并上传商品照片
3. 客服审核（1-2个工作日）
4. 审核通过后，系统发送退货地址
5. 用户寄回商品（建议使用顺丰/京东快递）
6. 仓库验收（1-3个工作日）
7. 退款到账（3-7个工作日，原路返回）

## 五、运费规则

- 质量问题：商家承担来回运费
- 非质量问题（七天无理由）：用户承担退货运费
- 换货运费：首次换货商家承担

## 六、退款标准

- 符合退货条件：全额退款（含原运费）
- 配件缺失：按配件售价扣除相应金额
- 包装破损：扣除包装费（最高50元）
- 商品有使用痕迹：根据折损程度扣除10%-30%
