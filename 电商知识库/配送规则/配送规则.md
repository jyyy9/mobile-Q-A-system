# 智汇电商 - 配送规则

## 一、发货时效

| 订单类型 | 发货时间 |
|---------|---------|
| 现货商品 | 下单后24小时内发货 |
| 预售商品 | 按页面标注的预售日期发货 |
| 定制/刻字商品 | 3-5个工作日发货 |
| 大促期间(618/双11/双12) | 2-5个工作日内发货 |
| 工厂直发商品 | 48小时内发货 |

### 特殊说明
- 工作日不包括周六、周日及法定节假日
- 16:00前付款的订单当天发货，16:00后付款的订单次日发货
- 极端天气（台风、暴雪等）可能延迟发货
- 疫情管控区域可能延迟发货，待管控解除后第一时间发出

### 大件商品运费
- 手机产品统一按小件标准收费
- 笔记本电脑及平板：按标准运费x1.5倍
- 配件（充电器、耳机、壳膜等）：满99元免运费，不满收6元

### 特殊运费政策
- 以旧换新订单：免运费（双向）
- 换货订单：首次换货免运费，第二次起用户承担
- 礼品订单：免运费（满200元）
- 企业批量采购：10000元以上免运费

## 五、签收须知

### 验货流程
1. 建议在快递员面前开箱检查
2. 确认外包装完好无损后签收
3. 如发现外包装破损、挤压变形，可当场拒收
4. 手机类商品开箱时请确认：屏幕无裂痕、边框无磕碰、配件齐全
5. 如发现外观问题，拍照留证后联系客服

### 代收/快递柜
- 快递柜代收后请及时取件（超时可能产生保管费）
- 他人代收后请尽快验货，如发现问题24小时内联系客服
- 小区驿站代收同样需要在签收后24小时内验货

### 签收后处理
- 签收后7天内支持无理由退货（手机需未激活）
- 签收后48小时内发现质量问题可申请换货
- 签收后请保留原包装和配件至少15天

## 六、配送异常处理

### 物流停滞
- 同一位置超过48小时未更新：联系客服催件
- 超过预计时效未送达：客服核实后可补偿5元运费券

### 包裹丢失
- 物流显示签收但实际未收到：24小时内联系快递+客服处理
- 运输途中丢失：商家重新补发或全额退款
- 快递公司确认丢失后，48小时内安排补发

### 地址错误
- 已发出但地址有误：联系客服尝试联系快递改地址
- 退回后重新发出：用户承担改址运费（15元）
- 未发出前：可直接在订单页面修改地址

### 拒收处理
- 无理由拒收：商品退回后，退款扣除发货运费
- 商品问题拒收：全额退款（需提供照片证明）
- 多次拒收：累计3次拒收将限制购买权限
