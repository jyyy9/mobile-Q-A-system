# 智汇电商 - 以旧换新专项规则

---

## 一、以旧换新概述

本店提供手机以旧换新服务，用户可将旧手机折价抵扣购买新手机的部分费用，同时享受额外补贴。

### 适用品牌
所有主流品牌的手机均可参与以旧换新，包括不限于：Apple、Samsung、Xiaomi、Huawei、OPPO、vivo、OnePlus、Honor、Realme、iQOO、魅族、索尼、Google等。

### 适用新机
旧机折价可用于购买本店任何在售新机。

## 二、旧机估价标准

### 2.1 估价影响因素

估价主要基于以下六个维度：

| 维度 | 具体影响 |
|------|---------|
| 品牌与型号 | 品牌溢价、市场供需关系 |
| 存储容量 | 同型号不同容量价差 |
| 外观成色 | 屏幕/边框/后盖的完好程度 |
| 功能状况 | 各项功能是否正常 |
| 配件齐全度 | 是否有充电器、数据线、包装盒 |
| 市场行情 | 新机价格波动、二手市场行情 |

### 2.2 外观成色等级

| 成色等级 | 定义 | 折价比例 | 说明 |
|---------|------|---------|------|
| 完美 | 全新未拆封/仅拆封未使用 | 70%-85% | 无任何使用痕迹 |
| 优秀 | 使用3个月内 | 60%-70% | 屏幕无划痕，边框微使用痕迹 |
| 良好 | 使用6-12个月 | 50%-60% | 轻微划痕，无磕碰 |
| 一般 | 使用1-2年 | 35%-50% | 有划痕和轻微磕碰 |
| 较差 | 使用2年以上 | 20%-35% | 明显磕碰划痕，功能正常 |
| 很差 | 功能有损 | 5%-20% | 屏幕碎裂/功能故障/电池严重老化 |

### 2.3 扣价标准

| 问题 | 扣价幅度 | 说明 |
|------|---------|------|
| 屏幕有划痕 | -5%-10% | 不影响正常使用 |
| 屏幕碎裂 | -20%-40% | 按碎裂程度扣减 |
| 后盖玻璃碎裂 | -10%-20% | 单换后盖价格 |
| 边框有明显磕碰 | -5%-10% | 影响美观 |
| 摄像头镜片碎裂 | -5%-15% | 不影响成像扣5%，影响成像扣15% |
| 电池健康度低于80% | -5%-10% | 需要更换电池 |
| 无法开机 | -50%-70% | 功能严重故障 |
| 进水/受潮 | -50%-80% | 检测到进水试纸变色 |
| 面容/指纹识别故障 | -15%-25% | 生物识别模块故障 |
| Wi-Fi/蓝牙故障 | -10%-20% | 无线连接功能故障 |
| 缺少充电器/数据线 | -3%-5% | 缺少原装配件 |
| 缺少包装盒 | -2%-3% | 影响二次销售 |
| 更换过非原厂配件 | -10%-20% | 非原厂屏幕/电池等 |
| 序列号异常/有锁/黑解 | 不予回收 | 视为问题机 |

### 2.4 不予回收的情况
- 山寨机、高仿机、妖机
- 有锁机、黑解机、卡贴机
- 改码机、套保机、翻新拼装机
- 序列号被涂改或无法读取的设备
- 无法解除账户锁的设备（iCloud锁/华为帐号锁/小米帐号锁等）
- 已严重变形或主板断裂的设备
- 爆炸/起火烧毁的设备

## 三、以旧换新流程

### 3.1 在线估价流程
1. 在商品页面点击"以旧换新"
2. 选择旧机品牌、型号、容量
3. 填写旧机外观成色（屏幕、边框、后盖）
4. 填写功能状况
5. 系统自动生成估价（保价48小时）
6. 确认估价后下单购买新机

### 3.2 回收质检流程
1. 下单后顺丰上门取旧机（免运费）
2. 旧机送达质检中心（1-2个工作日）
3. 专业工程师进行外观检测和功能检测
4. 生成最终回收价格
5. 用户确认价格后抵扣新机款
6. 旧机完成数据清除和恢复出厂设置

### 3.3 价格确认
- 估价与实际回收价可能有±10%浮动
- 如实际回收价低于估价，用户可选择：
  a) 接受价格，继续交易
  b) 拒绝价格，旧机免费退回（免运费）
  c) 拒绝价格，旧机转为门店回收（需到店自取）
- 价格确认后，差额在24小时内退还至用户账户

## 五、注意事项

### 5.1 数据安全提示
- 寄出旧机前请务必备份重要数据
- 请关闭查找我的iPhone/华为帐号/小米帐号等防盗功能
- 建议恢复出厂设置清除个人数据
- 本店不对旧机中的数据丢失负责

### 5.2 旧机寄送要求
- 请妥善包装旧机，建议使用原包装或气泡膜包裹
- 快递为顺丰到付，由本店承担运费
- 旧机寄出后请保留快递单号

### 5.3 隐私保护承诺
- 收到旧机后，质检中心将在24小时内进行数据清除
- 数据清除采用符合国家标准的覆写擦除方式
- 用户可要求出具数据清除证明

### 5.4 取消交易
- 估价后24小时内可无条件取消
- 旧机已寄出但在质检完成前可取消，需承担已产生的运费
- 质检完成并确认价格后不可取消
- 取消以旧换新后，新机的换新补贴将取消，其他优惠不受影响
