## 三、优惠叠加规则

### 3.1 叠加规则表

| 优惠组合 | 是否可叠加 | 说明 |
|---------|-----------|------|
| 满减券 + 品类券 | 可叠加 | 先满减再品类 |
| 满减券 + 新人券 | 不可叠加 | 二选一 |
| 满减券 + 会员折扣 | 可叠加 | 先用会员折扣再满减 |
| 品类券 + 会员折扣 | 可叠加 | 先用会员折扣再品类券 |
| 秒杀 + 优惠券 | 不可叠加 | 秒杀价已是最优 |
| 大促满减 + 店铺券 | 可叠加 | 平台券+店铺券双重优惠 |
| 购物金 + 优惠券 | 可叠加 | 购物金可折上折 |
| 积分 + 优惠券 | 可叠加 | 积分抵扣不受券影响 |

### 3.2 关键规则
1. 单笔订单最多使用 **2张** 优惠券
2. 优惠计算顺序：会员折扣 → 满减券 → 品类券 → 购物金抵扣 → 积分抵扣
3. 已取消订单使用的优惠券，有效期不变退回账户
4. 部分退款时，按退款金额占订单比例扣除已使用的优惠金额
5. 优惠券过期后自动作废，不予补发（大促特殊券除外）

## 八、活动注意事项

### 8.1 秒杀规则
- 每天10:00/14:00/20:00三场，商品限量
- 秒杀商品售后规则同正常商品
- 秒杀价不可用优惠券
- 秒杀商品发货时间可能延长至48小时

### 8.2 预售规则
- 预售定金不予退还（如未付尾款）
- 预售商品发货时间以页面标注为准
- 预售优惠不与现货优惠重叠
- 预售订单可使用优惠券（付尾款时使用）

### 8.3 禁止与限制
- 同一用户（同一账号/手机号/地址）仅限享受一次新人优惠
- 禁止使用外挂/脚本抢购秒杀商品
- 发现恶意套取优惠券行为的，将取消订单并封号
- 批量购买的订单可能不适用部分优惠活动

一、优惠券类型

1. 新人优惠券：新用户注册后可领取满100减20优惠券一张。

2. 满减券：
- 满1000减50
- 满2000减120
- 满5000减300

3. 折扣券：部分商品可享受9折或8.5折优惠。

4. 免运费券：全场通用，不限金额。


二、使用规则

1. 每笔订单限使用一张优惠券，不可叠加。

2. 优惠券不可与满减活动同时使用（以优惠力度大者为准）。

3. 部分特价商品、预售商品不参与优惠券抵扣。

4. 优惠券过期后自动作废，不予补发。


三、获取方式

1. 新用户注册即送新人券。

2. 关注店铺可领取关注礼券。

3. 会员每月可领取专属优惠券。

4. 参与店铺活动（秒杀、抽奖等）有机会获得大额券。


四、退款时的优惠券处理

1. 全额退款：优惠券退回，有效期不变。

2. 部分退款：按退款金额比例扣除优惠金额，剩余优惠券不退。

3. 使用优惠券的订单发生退货后，优惠券不予补发。
