# 智汇电商 - 隐私与数据安全政策

---

## 一、信息收集

### 1.1 我们收集的信息

为了向您提供商品购买、订单配送、售后服务等基本功能，我们需要收集以下信息：

| 信息类型 | 收集目的 | 是否必须 |
|---------|---------|---------|
| 姓名/昵称 | 用于注册账号、订单处理 | 是 |
| 手机号码 | 注册验证、订单通知、物流提醒 | 是 |
| 收货地址 | 商品配送 | 是 |
| 电子邮箱 | 发送电子发票、订单确认 | 否 |
| 支付信息 | 完成支付交易 | 是 |
| 订单信息 | 订单处理、售后服务 | 是 |
| 设备信息 | 提升用户体验、安全验证 | 否 |
| 浏览记录 | 商品推荐优化 | 否 |
| 位置信息 | 就近配送、门店定位 | 否 |

### 1.2 信息收集方式
- 注册/登录时您主动填写的信息
- 下单/支付过程中产生的订单信息
- 与客服沟通时的通话/聊天记录
- 您对商品的评价和反馈
- 您参与活动时提交的信息

### 1.3 Cookie及同类技术
- 我们使用Cookie和类似技术来记住您的登录状态和购物车信息
- 您可以设置浏览器拒绝Cookie，但这可能影响部分功能使用
- 我们不会通过Cookie获取您的个人隐私信息

## 二、信息使用

### 2.1 信息使用目的
- 处理您的订单和完成交易
- 提供售后服务和客户支持
- 向您发送订单状态和物流通知
- 改善和优化我们的服务
- 向您推荐您可能感兴趣的商品
- 预防和检测欺诈行为

### 2.2 信息使用原则
- 未经您明确同意，我们不会将您的个人信息用于本政策未载明的其他用途
- 如要用于其他用途，我们会重新征得您的同意
- 匿名化处理后的信息可用于数据分析和业务优化

---

## 三、信息共享与披露

### 3.1 信息共享

我们仅在以下情况下与第三方共享您的必要信息：

| 第三方 | 共享信息 | 目的 | 保障措施 |
|-------|---------|------|---------|
| 物流公司 | 姓名、电话、地址 | 商品配送 | 签订保密协议 |
| 支付机构 | 订单编号、支付金额 | 完成支付 | PCI-DSS认证 |
| 品牌方/售后 | 设备信息、故障描述 | 保修维修 | 签订保密协议 |
| 短信/邮件服务商 | 手机号/邮箱 | 发送订单通知 | 数据加密传输 |

### 3.2 信息不共享的承诺
- 我们不会将您的个人信息出售给任何第三方
- 我们不会将您的个人信息用于与本平台无关的商业推广
- 我们不会将您的个人信息提供给非合作第三方

### 3.3 法定披露
在以下情况下，我们可能依据法律要求披露您的个人信息：
- 根据法律法规、诉讼或政府主管部门要求
- 为保护社会公共利益
- 为保护本平台或其他用户的合法权益

---

## 四、信息存储与保护

### 4.1 存储位置
您的个人信息存储在中国境内的服务器上，数据不出境。

### 4.2 存储期限
- 账号存续期间，您的个人信息持续保存
- 账号注销后，我们将在30天内删除您的个人信息
- 法律法规要求保存的数据（如交易记录）将在法定期限内保存
- 超过法定保存期限后，相关信息将被彻底删除或匿名化处理

### 4.3 安全技术措施

| 安全措施 | 说明 |
|---------|------|
| SSL/TLS加密传输 | 所有数据传输采用256位加密 |
| 数据脱敏处理 | 展示时对敏感信息进行部分隐藏 |
| 防火墙和入侵检测 | 防止未经授权的数据访问 |
| 访问权限控制 | 员工访问用户数据需严格授权 |
| 定期安全审计 | 每季度进行安全漏洞扫描 |
| 数据备份 | 每日数据备份，防止数据丢失 |

### 4.4 安全事件处理
- 如发生数据泄露等安全事件，我们将在72小时内通知受影响的用户
- 通知内容包括事件原因、可能影响、已采取的补救措施
- 同时向相关监管部门报告

## 五、用户权利

### 5.1 您的权利

| 权利 | 说明 | 操作方式 |
|------|------|---------|
| 知情权 | 了解我们收集了哪些个人信息 | 查看本隐私政策 |
| 访问权 | 访问和查看您的个人信息 | 我的→个人信息 |
| 更正权 | 更正不准确的个人信息 | 我的→个人信息→修改 |
| 删除权 | 删除您的个人信息 | 联系客服申请 |
| 撤回同意权 | 撤回对信息收集的同意 | 系统设置→隐私设置 |
| 注销账号 | 删除账号及所有数据 | 我的→设置→账号注销 |
| 投诉权 | 对信息处理提出投诉 | 联系客服或监管部门 |

### 5.2 账号注销
- 您可以通过"我的→设置→账号注销"申请注销账号
- 注销后，您的个人信息将在30天内被删除
- 注销后无法恢复，请提前备份您的数据
- 注销后未完成的订单将被取消

## 六、账户安全提示

### 6.1 密码安全
- 请设置包含字母、数字、特殊字符的强密码（至少8位）
- 不要与其他网站使用相同的密码
- 定期更换密码（建议每3个月）
- 不要将密码告知他人
- 如怀疑密码泄露，请立即修改

### 6.2 账号防盗指南
- 不要点击不明链接和附件
- 不要在非官方APP/网站输入账号密码
- 开启登录二次验证（推荐）
- 经常检查登录设备列表，移除陌生设备
- 如发现异常登录，立即修改密码并联系客服
- 不要将验证码告知任何人（包括自称客服的人员）

### 6.3 防诈骗提醒
- 本店客服不会向您索要支付密码、银行卡号、CVV码
- 本店客服不会引导您进行转账操作
- 任何以"退款""解冻""保证金"为由要求转账的都是诈骗
- 收到可疑信息请通过官方渠道核实
- 如遭遇诈骗，请立即报警并联系客服

## 七、未成年人保护

- 未满14周岁的未成年人在使用本平台服务前，需征得监护人的同意
- 我们不会主动收集未成年人的个人信息
- 如发现未经监护人同意收集了未成年人信息，我们将及时删除
